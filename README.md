Мобильный плеер и офлайн-архив музыки Monster Siren Records (塞壬唱片-MSR) с загрузкой треков, альбомов и синхронизированных текстов (LRC) для прослушивания без интернета.

- 🌐 **Страница проекта:** https://neponum.github.io/monster-siren-fan-app/
- 📦 **Скачать APK (последний релиз):** https://github.com/neponum/monster-siren-fan-app/releases/latest/download/app-release.apk
- 📁 **Исходный код:** https://github.com/neponum/monster-siren-fan-app

## Возможности

- Каталог альбомов и треков Monster Siren Records с поиском.
- Офлайн-загрузка альбомов, треков и LRC-текстов.
- Постоянный мини-плеер, полноэкранный «виниловый» плеер, очередь, shuffle/repeat.
- Избранное, режим «только офлайн», статистика занятого места.
- Лента официальных новостей MSR.
- **Виджет-плеер 2×2 на главном экране:** обложка, трек, play/pause и переключение треков.
- **Личные плейлисты:** создание, переименование, удаление, добавление треков и прослушивание.
- **Свайп из «недавних» останавливает музыку** — фоновое воспроизведение не продолжается.
- **Автообновление:** приложение при запуске проверяет GitHub Releases и предлагает скачать и установить новую версию.

## Установка

1. Скачайте `app-release.apk` из [последнего релиза](https://github.com/neponum/monster-siren-fan-app/releases/latest).
2. Откройте файл на устройстве. При запросе Android разрешите установку из неизвестных источников для этого приложения.
3. При первом запуске появится дисклеймер — подтвердите его.

## Как работают обновления

- При каждом запуске приложение запрашивает `https://api.github.com/repos/neponum/monster-siren-fan-app/releases/latest`.
- Если тег релиза (например `v1.1`) новее текущей версии, появляется диалог с примечаниями к релизу и кнопкой «Скачать и установить».
- APK скачивается с GitHub Releases и открывается системным установщиком. Одно подтверждение установки — это ограничение Android (бесшумная установка невозможна без root/system-прав).
- Кнопка «Позже» запоминает тег: до выхода следующей версии диалог не показывается автоматически. Проверить обновления вручную можно в разделе **INFO**.

### Как выпустить обновление

1. Увеличьте `versionCode` и `versionName` в `app/build.gradle.kts`.
2. Сделайте коммит и тег вида `v1.1`, отправьте их на GitHub:
   ```bash
   git tag v1.1
   git push origin main --tags
   ```
3. GitHub Actions сам соберёт подписанный APK и прикрепит его к релизу `v1.1`.
4. Приложение пользователей обнаружит обновление при следующем запуске.

Для работы CI нужны secrets репозитория:
- `KEYSTORE_BASE64` — base64 содержимого `my-upload-key.jks`;
- `STORE_PASSWORD`, `KEY_PASSWORD` — пароли keystore;
- ключ в keystore должен называться `upload` (`KEY_ALIAS`).

Keystore и `.env` в репозиторий **не коммитятся** (см. `.gitignore`).

## Сборка локально

Требуются JDK 21, Android SDK (platform android-36, build-tools 36.1.0).

```bash
cp .env.example .env        # при необходимости
echo "sdk.dir=$HOME/Android/Sdk" > local.properties
KEYSTORE_PATH="$PWD/my-upload-key.jks" STORE_PASSWORD=... KEY_PASSWORD=... \
  ./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/app-release.apk`.
