# Changelog

## [1.2] - 2026-11-21

### Виджет
- Полностью переработан виджет: компактный 4×2 в стиле YouTube Music / Spotify.
- Обложка, название трека и исполнитель теперь читаются с первого взгляда.
- Кнопки «назад», play/pause и «вперёд» управляют воспроизведением, не открывая приложение.
- Виджет больше не растягивается по вертикали: только 2 строки.

### Плеер
- Очередь воспроизведения сохраняется и восстанавливается после перезапуска процесса.
- Свайп приложения из «недавних» останавливает музыку и сбрасывает уведомление.

### Обновления
- После обновления приложение показывает экран «Что нового».
- В диалоге обновления отображается список изменений и ссылка на релиз на GitHub.

## [1.1] - 2026-11-21

- Добавлен виджет-плеер на главный экран.
- Свайп приложения из «недавних» останавливает воспроизведение.
