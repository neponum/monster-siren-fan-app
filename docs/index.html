// Возможности

Каталог MSR

Альбомы и треки с поиском и синхронизацией каталога.

Офлайн-архив

Загрузка треков, альбомов и синхронизированных LRC-текстов.

Плеер

Мини-плеер, виниловый экран, очередь, shuffle и repeat.

Виджет-плеер

Обложка, трек и управление воспроизведением на главном экране.

Автообновление

Проверка новых версий прямо в приложении.

// Установка и обновления

  1. Скачайте app-release.apk из последнего релиза.
  2. Откройте файл и разрешите установку из неизвестных источников.
  3. При первом запуске подтвердите дисклеймер.
  4. Далее приложение само проверит наличие новой версии при запуске и предложит её установить.

Бесшумная установка обновлений на обычном Android невозможна — потребуется одно подтверждение системным установщиком. Проверить обновления вручную можно в разделе INFO.

// Для разработчиков

Обновление выпускается тегом v1.1: GitHub Actions собирает подписанный APK и прикрепляет его к релизу. Подробности — в README репозитория.
